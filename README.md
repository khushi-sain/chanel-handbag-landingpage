# CHANEL Luxury Handbag Landing Page

A premium, single-product luxury handbag landing page inspired by a clean white, cream, and gold fashion aesthetic. The page focuses on creating a strong first impression through elegant typography, product-focused visuals, smooth animations, and subtle micro-interactions.

## ✨ Features

* Premium CHANEL-inspired luxury UI
* Single handbag product presentation
* Responsive design for desktop, tablet, and mobile
* Modern semantic HTML5 structure
* Pure CSS3 animations and transitions
* Vanilla JavaScript interactions
* Scroll reveal animations using Intersection Observer
* Interactive handbag hover/parallax effect
* Animated gold CTA with metallic shine
* Floating particles and orbital animations
* Animated product image presentation
* Add to Bag interaction with animated counter
* Toast notification after adding the product
* Subtle cursor glow effect
* Hidden Konami Code easter egg
* `DECISIONS.md` explaining implementation choices

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Google Fonts
* Intersection Observer API

## 🚀 How to Run

No installation or build process is required.

1. Download or clone the repository.
2. Keep `index.html`, `style.css`, `script.js`, and `bag.png` in the same folder.
3. Open `index.html` in a browser.

For the best experience, use a modern browser such as Chrome, Edge, Firefox, or Safari.

## 🎨 Design Direction

The interface uses:

* White and warm cream backgrounds
* Elegant gold accents
* Serif typography for luxury headlines
* Minimal sans-serif typography for supporting content
* Large product-focused compositions
* Rounded editorial product cards
* Subtle shadows and metallic effects

The goal is to make the product feel premium without overcrowding the page.

## 🎬 Animations & Interactions

### Scroll Reveal

Sections smoothly fade in and move upward when they enter the viewport.

### Product Motion

The handbag gently floats and responds to mouse movement on desktop.

### Gold CTA

The "Add to Bag" button includes a subtle metallic shine, hover lift, and gold glow.

### Product Shine

A soft light sweep moves across the product card to create a premium editorial effect.

### Floating Particles

Small gold particles move subtly around the hero section.

### Orbit Animation

Thin gold orbital rings rotate slowly around the product to add depth.

### Add to Bag

Clicking "Add to Bag" updates the bag counter and displays a confirmation toast.

## 🎮 Easter Egg

A hidden Konami Code easter egg is included.

Enter:

```text
↑ ↑ ↓ ↓ ← → ← → B A
```

A hidden luxury-themed message appears on the page.

## 📱 Responsive Design

The layout is optimized for:

* Desktop
* Tablet
* 390px mobile screens
* Larger 1440px desktop screens

The page uses CSS Grid, Flexbox, responsive typography, and media queries to prevent horizontal scrolling.
